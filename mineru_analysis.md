## 🚀 Killer Features для научных документов

### 1. **Мультимодальный VLM парсинг** (революция!)
- Единственный инструмент с **собственной VLM моделью < 1B параметров**
- Превосходит модели 72B по качеству парсинга
- **10,000+ токенов/сек** на одной RTX 4090

### 2. **Идеальная обработка научного контента**
- ✅ **LaTeX формулы** → автоматическая конвертация с UniMERNet
- ✅ **Таблицы** → HTML с сохранением структуры (RapidTable)
- ✅ **Изображения и графики** → извлечение с подписями
- ✅ **Сложные layouts** → multi-column, вложенные структуры
- ✅ **84 языка** → включая математические символы и акценты

### 3. **Почему НЕ s2orc-doc2json**
```python
# s2orc-doc2json (старый подход)
- Последнее обновление: 2020
- Плохо работает с формулами
- Требует ручной очистки JSON
- Нет поддержки современных PDF

# MinerU (современный подход)
- Активная разработка: еженедельные обновления
- End-to-end pipeline без ручной работы
- Поддержка PPOCRv5 для рукописного текста
- Автоматическая очистка и структурирование
```


## 🎯 Специально для Paper2Code

### Прямая интеграция возможна через:
1. **Python API**
```python
from mineru import MinerU

miner = MinerU(backend="vlm-sglang")
result = miner.parse("arxiv_paper.pdf")
# Получаем структурированный JSON для Paper2Code
```

2. **REST API** (новое в 2.1.0)
```bash
# Запуск сервера
mineru-api

# POST запрос
curl -X POST http://localhost:8000/parse \
  -F "file=@paper.pdf" \
  -F "backend=vlm"
```

3. **Gradio WebUI** для быстрого тестирования
