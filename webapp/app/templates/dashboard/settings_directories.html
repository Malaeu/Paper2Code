Directory Usage Guide

Directory configurations are used by Paper2Code to store various files:

  • Uploads

    Temporary storage for uploaded papers

    Required
  • Papers

    Location where processed papers are stored

    Required
  • Data

    Location for datasets and other data files

    Required
  • Outputs

    Directory where generated code is stored

    Required
Important Notes

Make sure that directory paths exist and have proper permissions. The application needs read and write access to all configured directories. When you change directory configurations, the "Update Project Paths" button can be used to update all existing projects to use the new paths.
