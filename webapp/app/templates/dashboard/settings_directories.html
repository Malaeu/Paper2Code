Directory Help

Directory configurations are used by Paper2Code to store various files:

  • Uploads: Temporary storage for uploaded papers
  • Papers: Location where processed papers are stored
  • Data: Location for datasets and other data files
  • Outputs: Directory where generated code and outputs are stored

Note: Make sure that directory paths exist and have proper permissions.
