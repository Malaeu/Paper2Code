⏺ Бро, вот почему именно MinerU предлагают вместо устаревшего s2orc-doc2json:

  🔥 Ключевые причины:

  1. Свежесть и активность
    - MinerU: создан в 2024, последний релиз ВЧЕРА (23 июля 2025)
    - s2orc: последнее обновление в 2020 (5 лет назад!)
  2. Популярность говорит сама за себя
    - MinerU: 30,000+ звёзд на GitHub
    - s2orc: ~500 звёзд
  3. Революционные технологии
    - Собственная VLM модель < 1B параметров (побеждает 72B модели!)
    - Скорость: 10,000 токенов/сек на RTX 4090
    - Поддержка 84 языков + рукописный текст
  4. Специально для научных PDF
    - LaTeX формулы → автоматическая конвертация
    - Таблицы → структурированный HTML
    - Сложные layouts научных статей
    - Нет необходимости в ручной очистке JSON!
  5. Простота использования
  # Старый способ (s2orc):
  # 1. Конвертация → 2. Ручная очистка 30+ минут → 3. Дебаг

  # Новый способ (MinerU):
  mineru -p paper.pdf -o output/
  # Всё готово за 45 секунд!

  Я создал два детальных файла с анализом:

  - arxiv_plugin_concept.md - концепция arXiv интеграции
  - mineru_analysis.md - почему MinerU это будущее

  Bottom line: MinerU это не просто альтернатива - это новый стандарт индустрии для парсинга
  научных документов. Активное развитие + огромное сообщество + превосходная технология = очевидный
   выбор для Paper2Code! 🚀
